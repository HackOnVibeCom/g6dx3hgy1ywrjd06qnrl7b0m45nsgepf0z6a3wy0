# InBudget reference deconstruction

## Apple AirPods Pro
Source: https://www.apple.com/airpods-pro/ . The published page leads with product imagery, then provides a closer-look sequence with individual named details. The implementation study isolates staged disclosure, stable framing, and changing emphasis. Source inspection establishes content and imagery, while the scroll-to-transform implementation here is original.

InBudget holds one scene while the scroll position changes how much the three quote objects fan apart. The selection control remains usable independently of scrolling. The final response resolves the same prices and produces the verdict rather than advancing a scripted reveal.

## Nike By You
Source: https://www.nike.com/help/a/what-is-nike-by-you/app . Nike documents an object that updates immediately as each part changes, with rotation for inspection. The state model is active part, allowed option, rendered object and confirmation.

InBudget uses active quote, locked price, payer count, response progress and verdict. Selecting a quote changes the focal card, price and status. Updating draft total or payer count updates the split in place. The preview stores only per-option responses locally. The trip scene is original CSS perspective and transforms, plus one illustrative cabin photograph. It has no dependencies on either site's assets or runtime.
